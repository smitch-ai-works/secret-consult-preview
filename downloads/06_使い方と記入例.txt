初収益を狙う「抜け道」マネタイズ

【この教材で作るもの】
完成の目印初期設定の状態と、未完了の一段階・次の完成物を言える。

最初に潰すのは、報酬設定の抜け。
紹介する前に、投稿用アカウントと自分のリンクを一組で確認します。
01 / 登録 / 利用する提携先に、投稿するアカウントを登録する。 / 02 / 承認 / 申請中・承認済みなどの状態を、管理画面で確かめる。 / 03 / 個別リンク / 自分のアカウントと対象商品へ紐付くリンクか確認する。 / 04 / 行き先 / 実際に開き、商品名・購入条件が紹介内容と合うか見る。
動画を増やしても、成果の紐付けに抜けがあれば回収できません。「アカウント承認」と「個別リンク」が初期設定の要点です。利用先の現行手順で設定し、確認日と状態を下のシートへ残してください。
下の初期設定メモに、承認状態とリンクの確認日を書く。

お手本5〜10件から、一本を選ぶ。
一番数字が大きい投稿ではなく、自分が制作まで通せる参考を探します。
見るところ / メモする内容 / 商品と相手 / 何を、どんな人のどんな場面に紹介しているか。 / 冒頭と展開 / 最初に何を見せ、次に何を伝えているか。 / 素材 / 手元・実物・字幕など、自分で用意できるものは何か。 / 反応と日付 / 投稿日、確認日、再生・いいね・コメントなど確認できた値。
最初の参考は5〜10件を目安に集め、投稿の作り方やプロフィール等を観察します。再生の絶対数だけで選ばず、反応や制作条件も並べると、自分の一本へ使う構造を選べます。反応数から売上を逆算する必要はありません。
参考URLを並べ、自分で使える素材と不足を一行ずつ書く。

一本を、四つの場面へ落とす。
紹介文だけ先に増やさず、伝える言葉と使う素材を同時に決めます。
01 / 場面 / 誰の、いつの選び方か。外へ持っていく道具を選ぶ場面など。 / 02 / 事実 / 確認した仕様を、形や動きが分かる素材で見せる。 / 03 / 理由 / その仕様が、相手の場面で何を確かめる材料になるか。 / 04 / 案内 / 自分のリンク先で、サイズや購入条件等を確認してもらう。
携帯用ブラシなら「折りたためる」という言葉だけで終わらず、開く・閉じる・ケースへしまう動きを見せる、という設計ができます。これは架空商品の練習例です。自分の商品では、確認した仕様と使える素材へ置き換えます。
四場面それぞれに、言葉一つ・素材一つ・確認する事実一つを割り当てる。

公開前の一回確認で、つなぎ目を見る。
原稿・映像・案内先・計測の準備が、同じ商品でつながっているかを確認します。
確認するもの / 終わった目印 / 原稿 / 商品名・仕様・数値を、確認元と照合した。 / 映像と文字 / 見せたい形や動作を隠さず、読める。 / 案内先 / 自分のリンクで、想定の商品と条件ページが開く。 / 記録欄 / 公開日・見直す日・記録する指標を決めた。
完成の基準を先に置くと、いつまでも道具の準備を続けずに済みます。未確認の条件や使えない素材が残るときは、その箇所を解消してから公開します。投稿は自分のアカウントで行い、このページから送信されることはありません。
原稿を声に出して読み、素材と案内先を順に確認する。

最初の反応を、次の一本へ戻す。
一回の結果で向き不向きを決めず、変える場所を一つ選びます。
01 / 記録する / 同じ公開後日数で、表示・クリック・発生・承認を分ける。 / 02 / 見返す / 反応した箇所と、途中で止まっている箇所を確かめる。 / 03 / 次を決める / 冒頭・素材・案内など、一つを変えて次の一本を作る。
ここで通す流れは、準備で終わらず投稿し、伸びた動画の理由を見て次に作ることまで含みます。最初の成果が出る時期や額は約束できませんが、何を確かめ、何を次に試すかは自分で決められます。
下の進行シートで未完了の一段階を選び、次の完成物を一つ決める。

【自分の記入欄】
登録・承認・個別リンク：［確認した場所・状態・日付］

条件：［報酬・成果・承認・購入の条件］

参考から選んだ構造：［URL・相手・冒頭・素材・日付］

四場面と使う素材：［場面→事実→理由→案内］

公開前の照合：［原稿・映像・案内先］

公開日・見直す日：［同じ期間で記録する数字］

次に終わらせる一つ：［不足と次の完成物］

画面で記入して「入力をまとめる」から、コピーまたはテキスト保存できます。入力は同じ端末・同じサイトのブラウザに残ります。別端末への移動用にはテキスト保存を使ってください。
