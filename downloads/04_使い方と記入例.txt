高単価報酬が生まれるカラクリ

【この教材で作るもの】
報酬・成果・承認・購入条件と、確認先が一枚にある。

商品価格と紹介報酬は、別の数字。
売価の何％という契約と、一件いくらという契約を区別します。
割合で決まる例 / 商品価格 2,000円 × 報酬率3％ / 一件の報酬は60円。 / 一件で決まる例 / 条件を満たした購入一件につき3,000円 / 商品価格とは別に、契約の報酬額を確認する。
どちらも仕組みを比べる計算例です。紹介されている案件には、商品代金と同じくらい、またはそれ以上の報酬が設定された例があります。ただし「AIを使うから高額」ではなく、紹介する案件・契約条件で報酬が決まります。
自分の案件が、割合型か固定額型かを条件ページで確かめる。

高い一件を、同じ一件として数えない。
成果になる行動と承認条件が違えば、報酬額だけでは比べられません。
確認する欄 / そこを見る理由 / 成果条件 / 購入・申込など、何が完了した一件なのかが違う。 / 対象者 / 初回限定など、対象外の人を案内しないため。 / 承認・否認条件 / 返品・取消等で、発生した成果が確定しない場合があるため。 / 購入者の条件 / 送料・継続・解約等が、選ぶ判断に関係するため。
報酬額だけを先に見ると、相手に合わない案件を選びやすくなります。自分が伝えられる商品事実と、購入する人が確認すべき条件をそろえてから、紹介できる候補かを判断します。
不明な欄を推測で埋めず、質問する確認先と日付を残す。

発生、承認、支払を分ける。
売れた件数と、確定して受け取れる額には段階があります。
01 / 発生 / 条件に該当する購入等が記録される。 / 02 / 承認・確定 / 案件ごとの確認を経て、対象の成果が確定する。 / 03 / 支払 / 利用サービスの締日・支払条件に沿って受け取る。
成果の発生と確定は、別の段階です。確定する時期は商品・契約によって違います。特定の締日や翌朝の通知時刻を全案件共通のルールにはせず、自分の管理画面・通知・利用条件で確認してください。
発生した日、確定する予定、支払条件を別にメモする。

リンクと承認は、投稿の前に。
商品ページが開くだけでは、本人の成果へ紐付く設定まで確かめたことにはなりません。
01 / 投稿用アカウントを確認 / 利用する提携先へ、投稿するアカウントを登録したか。 / 02 / 承認状態を確認 / 申請中か承認済みかを、現行の画面で確かめる。 / 03 / 自分の紹介リンクを確認 / 対象アカウント・案件・案内先が一致しているかを見直す。
アカウントの承認と個別リンク設定が不足すると、売れても自分の成果として連携されない点が説明されています。公開前の確認は、自分の利用サービスの手順と照らして行います。
登録先・承認状態・リンクの確認日を残す。確認のために購入する必要はありません。

残る金額まで、同じ条件で計算。
発生額をそのまま利益として扱わず、確定額と費用を分けます。
01 / 発生の計算例 / 3,000円 × 発生10件 = 30,000円。 / 02 / 確定の計算例 / 3,000円 × 承認8件 = 24,000円。 / 03 / 費用との差 / 確定24,000円 − 費用3,000円 = 21,000円。
これは計算の練習であり、実案件の獲得見込みではありません。下のシートで一件の条件を残し、計算欄では発生と承認を入れ分けられます。費用に何を含めたかもそろえると、比較しやすくなります。
一件の報酬・発生件数・承認件数・費用を別の欄へ入れてみる。
