手間を減らして回す 半自動化スキーム

【この教材で作るもの】
出力を見て、採る案と修正する箇所を自分で選べる。

一回分を、AIと人で受け渡す。
「全部作って」ではなく、確定した材料から次の完成物へ渡します。
01 / 人：材料を整える / 商品名・誤認識・数値・出所を確認する。 / 02 / AI：案を作る / 材料整理 → 構成 → 冒頭案を、必要な工程だけ頼む。 / 03 / 人：原稿を確定する / 事実と素材に合う案を選び、体験や効果の追加を除く。 / 04 / AIと整形ツール：字幕を整える / 自然なフレーズへ分割し、確認した時刻をSRT形式へ整える。 / 05 / 人：映像と音声で仕上げる / 編集ソフトへ取り込み、音声・改行・文字位置を直す。
この教材では、AIへ渡す六つの指示文と、その後に使えるSRT整形欄を用意しました。指示文の作成はこのページで行い、AIへの依頼は自分の利用するAIで行います。出力を確認してから次の工程へ渡してください。
いま必要な完成物を一つ選ぶ。構成があるなら冒頭案からでも始められる。

渡す前の修正で、後工程を軽くする。
文字起こしの誤りを、AIが正しい商品情報として広げないようにします。
人が先に確かめる欄 / 確認すること / 商品名・固有名詞 / 実物や商品ページの表記と一致するか。 / 数値と仕様 / サイズ、価格、回数等の出所があるか。 / 文章の区切り / 文の途中の改行や、別の話が混じっていないか。 / 体験・効果 / 自分が確認していない内容を、そのまま使っていないか。
文字起こしから商品名・誤認識・改行を人が直して、AIへ渡します。参考の内容を自分の商品へ置き換えるときは、元の語句を残すことより、自分の商品で言える事実へ合わせることを優先します。
原稿の各数値と商品名を、確認元へ一度戻してからAIへ渡す。

AIの案から、採るものを決める。
出来上がった文章をそのまま使わず、事実・映像・相手の場面の三つで選びます。
確認する出力 / その仕様は入力した事実と一致しているか。 / その一文に対応する実物の素材があるか。 / 相手の場面と、案内先がつながっているか。 / 修正の例 / 「どんなバッグにも入る」→サイズ未確認なら削る。 / 「使って驚いた」→自分の体験でなければ削る。 / 仕様を並べるだけなら、選ぶ場面を一つに絞る。
映像生成が完了したことと、商品を判断できる紹介が完成したことは別です。素材選びと微調整には、人の判断が残ります。案を比べたら採用する理由を一つ残し、確定原稿を次へ渡します。
確定原稿から未確認の一文を除き、使う素材を割り当てる。

フレーズと時刻を、別々に確かめる。
意味がつながる字幕の区切りと、音声に合う開始・終了時刻を分けて決めます。
01 / フレーズ分け / 確定原稿の語句を変えず、一度に読める長さへ区切る。 / 02 / 音声を聴いて時刻を取る / 各フレーズの開始・終了を、実際の音声に合わせる。 / 03 / SRTへ整形 / 連番・開始時刻・終了時刻・字幕本文の形で保存する。 / 04 / 編集ソフトで照合 / 字幕インポート後、音声と映像を再生して位置と区切りを直す。
AIが付けた仮の時刻だけで同期が完成するわけではありません。SRTを取り込んだ後は、人が音声へ合わせて微調整します。下の整形欄は、確認した秒数から正しいSRT書式を作る道具です。
次の「字幕をSRTにする」で、作例を変えて一度保存してみる。

同じ判断を、次の一回へ残す。
一回使ったら、入力材料と採用基準を保存して使い回します。
残すもの / 次に再利用できるもの / 確認済みの商品事実 / 毎回同じ仕様や条件を調べ直す前の出発点。 / 採用した原稿と素材 / 何を言い、何を見せたかの対応。 / 固定する語句 / 商品名・数値・案内先・確定した原稿。 / 直した箇所 / AIの案から削除・変更した理由。
半自動化で減らすのは、何度も同じ形へ整える手間です。商品選びや最終確認まで自動で正解になるわけではありません。材料・指示・出力・修正理由を一組で残すと、次回の依頼を短くできます。
指示文と採用原稿を保存し、次回変える材料だけを書き出す。

【自分の記入欄】
依頼する工程：［材料整理／構成／冒頭／照合／整形］

渡す材料：［相手・場面・仕様・出所・案内先］

ほしい出力：［表／4場面／3案／照合表など］

固定するもの：［語句・数値・順番・確定原稿］

確認すること：［出力と事実、素材、音声との一致］

【SRT整形】
08.htmlの「確認した時刻から、SRTを作る」で、開始秒 | 終了秒 | 字幕 の順に入力します。小数点以下3桁まで。出力は.srtで保存できます。保存後は編集ソフトへ取り込み、全編を音声と照合してください。

画面で記入して「入力をまとめる」から、コピーまたはテキスト保存できます。入力は同じ端末・同じサイトのブラウザに残ります。別端末への移動用にはテキスト保存を使ってください。
