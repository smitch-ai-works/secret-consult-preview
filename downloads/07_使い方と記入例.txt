本業と両立する「仕込み」の裏ワザ

【この教材で作るもの】
各作業枠の最後に、次回使えるものが残る。

「夜に作業」より、終わりを決める。
何をすれば終わりかが分かると、再開するたびの迷いを減らせます。
予定があいまい / 夜に、副業をする。 / 終わりが見える / 仕様を一つ確認し、出所をメモする。
「夜に作業する」は開始の予定。「仕様と出所を一つのメモへ」は完了の目印です。短い作業枠ほど、何をしたら終わりかを先に決めると次回へつなげやすくなります。
時間だけでなく、終わったと判断する状態を書く。

集める日、作る日、確かめる日。
同じ種類の作業をまとめた週間表の記入例。予定は自分の生活に合わせて変えます。
一週間の記入例 / 予定の合計 / 90 / 分 / 月 / 15 / 分 / 確認 / 商品の仕様と出所を一つ / 水 / 20 / 分 / 設計 / 相手・場面・事実を一枚に / 土 / 45 / 分 / 制作 / 一つ形にして事実を確認 / 日 / 10 / 分 / 記録 / 次に変える一点を残す / 予定の置き方の例です。必要時間や成果の目安ではありません。
例では、月曜に調査15分、水曜に設計20分、土曜に制作45分、日曜に記録10分。合計90分の予定の置き方です。実際に必要な時間は作業や経験で変わるので、自分の予定で組み直します。
例の90分は予定の合計。自分が使える枠へ置き換える。

人に頼むなら、完成の条件も渡す。
材料と作業範囲を一緒に渡すと、任せたことと確認することが分かれます。
原稿 / 確定した言葉 / 素材 / 使う範囲と出所 / 見本 / 完成の形 / まとめて渡す → 依頼した工程だけを任せる
任せるときは、確定原稿・使う素材・完成見本・納品形式をまとめます。依頼する工程を絞ると、自分が決める内容と、相手へ任せる整形作業を分けられます。
「いい感じに」だけで頼まず、五つをそろえる。

そのまま調整できる、依頼文の見本。
確定した原稿を、一行ごとのフレーズに整える作業の依頼例です。
原稿整形の依頼メモ / お願いしたいこと / 確定原稿を、意味がつながる一行へ区切る / 変えないもの / 語句・数字・意味・掲載順 / 完成の確認 / 抜け・追加・言い換えがないか / 納品形式 / UTF-8のテキスト。納期は相談して決める
「いい感じに整えて」では、完成の基準が共有できません。変えない語句、納品形式、確認する箇所まで書けば、どこまでお願いするかが具体的になります。
下の週間表と依頼シートで、自分の作業へ置き換える。

次に開いたとき、何から始める？
終わった場所と次の一手を残すと、そろえた材料から作業を再開できます。
今日の終わり / 材料のメモを保存 / 次回の最初 / 構成を一つ作る / 見直す日 / 変える一点を決める
今日の終わりに「次は、この材料で冒頭を三案つくる」と残す。作業が短くても、次回すぐ続けられる材料が残れば、準備をやり直す時間を減らせます。
下のシートへ、自分の一週間を入力する。

任せる前に、受け取り方まで決める。
確定原稿を字幕のフレーズへ分ける依頼を例に、依頼と確認を一組にします。
01 / 渡す / 確定原稿、改行の見本、商品名と数値の固定リスト。 / 02 / 頼む / 語句と順番を変えず、一度に読める意味の区切りへ改行する。 / 03 / 受け取る / UTF-8のテキスト。元原稿と照合できる状態で納品。 / 04 / 自分で確認 / 追加・抜け・言い換えがないか、音声と合う区切りか確かめる。
依頼した工程が終わっても、商品の事実や音声との一致まで自動で確定するわけではありません。下の依頼メモで、固定するものと納品形式を残しておくと、修正の依頼も具体的になります。
一つの作業だけを任せる前提で、材料・固定事項・納品形式・確認範囲を記入する。
