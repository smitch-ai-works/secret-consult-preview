稼ぎ方の常識を変える AI×〇〇

【この教材で作るもの】
自分が決めることと、AIへ頼む作業を言い分けられる。

AIが作るのは、紹介するための材料。
扱うのは、商品を紹介して成果条件を満たしたときに報酬を得る物販アフィリエイトです。
01 / 商品と条件を選ぶ / 紹介できる商品・報酬条件・素材を確認する。 / 02 / AIと紹介内容を作る / 事実を渡して、構成・台本・字幕の案を整える。 / 03 / 自分の案内先へつなぐ / 投稿を見た人が条件を確かめ、購入などの行動を選ぶ。 / 04 / 条件に沿って成果が確定する / 発生・承認・支払を、利用する案件の画面で確認する。
AIの出力を販売する仕組みではありません。紹介内容の制作にAIを使い、販売元の商品へ案内します。商品の配送や販売条件を用意する側と、紹介を作る自分の役割を分けると、最初に準備するものが見えます。
商品・相手・素材・案内先・成果条件を一つずつ挙げる。

お金と情報は、違う向きに動く。
商品代金、紹介報酬、紹介する情報を一本の線にしないで見ます。
流れ / 誰から誰へ / 起きること / 紹介の情報 / あなた → 見る人 / 選ぶ材料と、確認先を伝える。 / 商品代金 / 購入者 → 販売元 / 購入条件に同意して支払う。 / 紹介報酬 / 販売元・提携先 → あなた / 契約の成果条件と承認を経て支払われる。
「売れたら商品代金を自分が丸ごと受け取る」という形ではありません。報酬は契約で決まります。投稿の公開だけで確定するわけでもないため、発生と承認を分けて見ます。
自分の案件では、誰が承認し、どこに確定額が出るかを確認する。

顔を出すかより、何を見せられるか。
手元・商品の形や動き・字幕を組み合わせると、顔を出さずに説明できる場面があります。
用意する映像 / 自分で撮れる商品の形や使い方。 / 利用条件を確かめた提供素材。 / 映像で確かめること / 紹介文で言っている形・動きが実際に見える。 / 見る人が選ぶために必要な情報が隠れていない。
実物の手元を見せる方法と、AIで作った人物映像だけで紹介する方法では、伝わる情報が違います。実物でなければ確認できない形や使い方を、想像の映像で埋めないことが大切です。
商品について一つ言うたびに、それを見せられる素材があるか確認する。

AIへ渡す前に、人が決める。
指示を細かくする前に、相手と事実をそろえます。
01 / 人が決める / 誰の、どの場面に、どんな事実を伝えるか。 / 02 / AIへ頼む / 材料整理、順序の案、短い表現、原稿の整形。 / 03 / 人が戻して確かめる / 仕様・数値・体験・案内先を元の材料と照らす。
商品名や誤認識を直してからAIへ渡すことも、AIへ渡す前の実作業です。入力が曖昧なままでは、もっともらしい不足情報が混ざることがあります。未確認の事実は、確認する項目として残します。
AIへ渡す材料に、事実の出所と変えてはいけない語句を付ける。

最初に作るのは、一回分の紹介。
仕組みを理解したら、同じ商品で制作と計測をつなぎます。
01 / 設計 / 場面 → 商品の事実 → 選ぶ理由 → 案内。 / 02 / 制作 / その順番で、言葉と使う素材を一組ずつそろえる。 / 03 / 確認 / 案内先が開き、商品・条件・自分のリンクが一致するか見る。 / 04 / 記録 / 公開日と、同じ期間で見直す数字を残す。
道具を一度に覚えることより、一回分を最後まで通すことが先です。自分で一回流れを通すと、どの工程をAIへ頼むと助かるか、具体的に選べるようになります。
下の3問で、販売元・自分・AIの役割を説明できるか確かめる。

【自分の記入欄】
誰に届けるか：［一人の相手と使う場面］

何を見せるか：［確認した仕様・形・動き］

どこへ案内するか：［条件を確認できるページ］

報酬の条件：［成果になる行動と承認条件］
