収益化の型を丸ごと使える 独自テンプレ

【この教材で作るもの】
4場面すべてに、伝える言葉と使う素材がある。

「40代女性」から、使う場面へ近づく。
年代だけより、いつ何を選ぶ人かまで下ろすと、必要な情報が見えてきます。
まだ広い / 40代の女性 / ↓ / 一つの場面へ / 外出先で、髪を整えたい。 / 小さなバッグに、道具をしまいたい。 / ↓ / だから、閉じた形と収納した形を見せる。
「40代女性」だけだと、何を見せればよいか決まりません。「外出先で髪を整えたい」「小さなバッグへしまいたい」まで下ろすと、見せるべき形や動きが具体的になります。
自分の相手を「いつ・どこで・何を選ぶ人か」で書く。

折りたたみ式なら、しまう形も見せる。
持ち歩く道具を選ぶ人には、開いた形・閉じた形・収納した形が判断材料になります。
1 / 開いた形 / 使うときの形 / 2 / 折りたたんだ形 / 持ち運ぶときの形 / 3 / 収納した形 / ケースへしまう様子
この教材では、折りたたみ式・ケース付きという練習設定を使います。開く→閉じる→しまうの三つが見えれば、持ち運びを考える人が形を判断しやすくなります。実商品では、確認した仕様へ置き換えてください。
商品の仕様から、「見せると選びやすい情報」を一つ決める。

同じ商品でも、伝える軸は変えられる。
人の体験を作らず、確認できる仕様と、その人が選ぶ場面から組み立てます。
特徴だけ / 折りたたみ式。収納ケース付き。 / 選ぶ場面につなぐ / 持ち歩くなら、閉じた形としまい方も見たい。
「ケース付き」は特徴。「しまったときの形を確かめられる」は、選ぶ場面とのつながり。商品の特徴を、相手が気にする場面に結び付けるのが設計の中心です。
「その特徴が、なぜ相手に関係するのか」を足す。

完成する設計メモは、こんな一枚。
相手・場面・事実・理由・案内先が一枚につながれば、AIへ渡す材料にもなります。
携帯用ブラシの設計メモ / 相手と場面 / 外出先で、髪を整える道具を選ぶ人 / 確認した設定 / 折りたたみ式・収納ケース付き / 見せる理由 / 持ち運ぶ形と、しまい方を確かめられる / 案内先 / サイズと購入条件を確認できる商品ページ
相手と場面、確認した事実、見せる情報、案内先。一枚に並べると、伝える順番がつながります。原稿を書き始める前に、この段階で材料の抜けを見つけます。
下のシートで、記入例から自分の商品へ置き換える。

同じ材料を、AIへ渡せる形にする。
相手や商品の情報を決めておくと、原稿のたびに一から考え直さずに進められます。
05で整理 / 相手・場面・事実 / 08へ渡す / 同じ材料で指示文へ / AI / AIで案出し / 入力の事実から構成へ
下の設計シートで作った材料は、08の指示文へ引き継げます。新しい原稿のたびに相手や商品を決め直さず、同じ材料から構成や冒頭の案を比べてください。
設計を入力したら「この設計を08で使う」でつなぐ。

原稿へ渡す前に、四場面を照合する。
同じ商品の記入例で、仕様の言葉と見せる素材を一組ずつそろえます。
場面 / 伝えること / 使う素材 / 入口 / 外へ持っていくブラシを選ぶ場面。 / バッグと商品。 / 事実 / 折りたたみ式、ケース付き。 / 開く → 閉じる → ケースへしまう。 / 理由 / 使う形と、しまう形を確かめて選ぶ。 / 開いた形と収納した形。 / 案内 / サイズと購入条件を確認してもらう。 / 案内先と、確認する項目。
これは架空商品の記入例です。実商品では仕様の確認元と使える素材へ置き換えます。「便利」「おすすめ」だけで進めず、何を確かめると相手が選びやすいかを理由にします。
シートを保存すると、同じ端末・同じサイトの08で設計を読み込めます。

【自分の記入欄】
入口：［相手が自分ごとにできる場面］

商品の事実：［何を見せ、何を伝えるか］

選ぶ理由：［その仕様が、相手の場面にどう関係するか］

案内：［どこで、何を確認してもらうか］

画面で記入して「入力をまとめる」から、コピーまたはテキスト保存できます。入力は同じ端末・同じサイトのブラウザに残ります。別端末への移動用にはテキスト保存を使ってください。
