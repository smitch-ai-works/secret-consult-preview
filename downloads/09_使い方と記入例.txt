狙い目の〇〇市場 参入ルートを公開

【この教材で作るもの】
完成の目印今回のルート、検索語、二候補の不足、先に試す理由がある。

参入は、二つの入口から選ぶ。
未投稿の段階と、一回の制作を通せる段階では、探す候補の条件が違います。
まず一本を作る段階 / 参考の種類があり、自分で用意できる素材を見つけやすい候補。 / 大きな数字より、一本を完成できる構造を選ぶ。 / 制作・投稿を経験した段階 / 需要を確認でき、比較対象より競合の少ない周辺候補へ広げる。 / 参考が少なくても、自分で構成と素材を組めるか確かめる。
最初は参考を見つけやすい商品で練習し、制作経験がついたら周辺商品で市場の一部を狙う。この二つを分けて考えます。競合が少ないことだけを、売れる根拠にはしません。
下のシートで、自分の制作経験から今回のルートを選ぶ。

商品名から探し、足りなければ広げる。
最初から「美容」全体を見ず、紹介候補に近い順番で検索します。
01 / 商品名 / その商品で、どんな紹介が作られているかを見る。 / 02 / カテゴリ・悩みの語へ広げる / 参考が足りなければ、ヘアケア・スキンケア等の周辺へ広げる。 / 03 / 直近の投稿へ絞る / アプリの現行の絞り込みで、期間や反応順を確認する。 / 04 / 投稿を実際に開く / 冒頭・商品・動き・案内と、自分の素材で作れるかを見る。
スマホで商品名を検索し、参考が足りなければ大きいキーワードへ広げます。絞り込みの表示は現行画面で確認し、検索語・確認日・対象期間をメモします。上位に出たという理由だけで候補を決めず、内容を開いて観察します。
商品名の検索語と、次に広げるカテゴリ語を一つずつ決める。

一本から、アカウントまで見る。
一つの大きな数字だけでなく、複数の投稿と制作条件を並べます。
確認する場所 / 取り出す情報 / 参考投稿 / 冒頭の場面、見せる形や動き、文字、案内先。 / 同じアカウントの別投稿 / 同じ構造が複数あるか、商品や素材の種類は何か。 / 反応と日付 / 再生・いいね・コメント、投稿日と確認日。 / 自分の手元 / 同じ役割の素材を、自分で用意できるか。
参考が見つかったらアカウントへ進むと、同じ商品の別の見せ方を探せます。反応の値は観察した事実として残しますが、購入数や利益は公開の反応だけでは分かりません。使うのは構造であり、他人の素材や体験ではありません。
候補ごとにURL・確認日・構造・素材・不足の五つを残す。

候補を比べる軸は、需要と制作条件。
市場が大きいかどうかと、自分が着手できるかを同じ一つの点数にしないで見ます。
軸 / 確認できる材料 / まだ断定しないこと / 需要 / 案件側で確認できる情報、継続して見つかる関連投稿。 / 反応数だけからの売上推測。 / 競合 / 同じ商品や訴求を扱う投稿の種類と量。 / 競合が少ないので必ず売れる、という判断。 / 制作条件 / 使える素材・商品事実・案件条件・案内先。 / 素材不足のままで制作できる、という前提。
需要があり、比較対象より競合が少ない周辺候補は経験者が調べる方向の一つです。ただし当時の売れ筋が今も狙い目とは限りません。今回は利用できる条件と素材を確かめ、小さく一回を試す候補を選びます。
二候補を並べ、先に解消する不足と、その確認先を一つずつ書く。

調査を、一回の制作へ閉じる。
調べ続ける前に、一本で確かめる仮説と見直す日を決めます。
01 / 候補を選ぶ / 今の段階で制作でき、条件を確認できる一候補に絞る。 / 02 / 仮説を書く / 誰のどんな場面に、何を見せると判断しやすいか。 / 03 / 必要素材をそろえる / 原稿の事実に対応する形・動き・仕様を準備する。 / 04 / 一回を試して戻る / 公開日と見直す日を決め、同じ期間の反応を記録する。
選んだ候補は「売れる商品」の確定ではなく、調べた条件から今回試す候補です。反応を残すと、次に候補を変えるのか、同じ商品の見せ方を直すのかを判断する材料になります。
下の比較シートに、試す候補・理由・確認日・不足をまとめる。
