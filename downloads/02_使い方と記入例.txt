たった3ヶ月で月113万を生み出した極意

松岡さんの事例：2024年8月開始、同年10月に最高月利益113万円。伸びた2動画・1商品が寄与。運・商品・タイミングにも言及。自分の見込み収益とは分けて読みます。

【この教材で作るもの】
完成の目印参考・判断理由・自分の変更点・作業の再開場所が一枚にある。

113万円の前に、何をしていたか。
松岡さんの美容アフィリエイト事例から、結果と日々の判断を分けて読みます。
01 / 2024年8月に開始 / 会社の仕事と並行して、美容アフィリエイトに取り組む。 / 02 / 同年10月に最高月利益113万円 / 伸びた2本の動画・1商品が大きく寄与した事例。 / 03 / 帰宅後に、翌日分の2本を制作 / 翌日の昼・夜に投稿する準備をしていた。
この金額は松岡さんの事例です。商品・運・タイミングも重なったと本人が話しています。TikTok Shop開始以前の事例なので、当時の成果を現在の制度や自分の見込み収益へ置き換えず、調べ方・直し方・準備の仕方を取り出します。
自分が取り入れる判断を一つ選ぶ。金額や本数をノルマにはしない。

伸び始めを、観察メモへ変える。
直近の投稿を見つけても、「なぜ参考にするか」がなければ次に使えません。
01 / 商品名で探す / 直近約7日を一つの観察範囲にして、投稿日と確認日を残す。 / 02 / 同じ投稿を見返す / 数字が動いているか、冒頭・動き・文字・案内を確かめる。 / 03 / 一つに絞る / 自分の素材で再現できる構造と、改善したい一点を選ぶ。
松岡さんが挙げたコツの一つは、直近7日ほどで伸びている投稿を早く捉えることです。ここで集めるのは表現のコピーではなく、どんな場面から入り、何を見せ、何へ案内するかという順序です。確認した時刻も残すと、後からの思い込みを減らせます。
参考URL・投稿日・確認日・観察できたことを一組で残す。

一か所の違和感を、直す理由にする。
事例で実際に挙がった改善は、音とカットのズレを合わせることでした。
観察した違和感 / 音の合図より、映像の切り替えが遅れて見える。 / 内容を増やす前に、切り替わる瞬間を確かめる。 / 自分の制作で直す一つ / 使う音の合図を決める。 / 映像の動き・カットが、その瞬間に合うよう調整する。
「凝った動画を作る」だけでは、何を変えたか振り返れません。音と映像なら、どの合図とどの動作をそろえたかまで言葉にします。改善後に反応が変わっても、この一点だけが原因だとは決めず、記録を残します。
「何となく良くする」を、「どの瞬間を、どう直すか」に書き換える。

位置ではなく、伝える目的を受け継ぐ。
文字の場所も、商品を紹介する言葉も、自分の映像と商品の事実へ合わせます。
観察するもの / 自分の制作で確かめること / 文字の位置 / 顔・目・商品の動きを隠していないか。端末でも読めるか。 / 見せる順序 / 商品のどの形・動きが、選ぶ判断につながるか。 / 商品を選ぶ理由 / 自分の商品ページに、その仕様や条件が書かれているか。
事例では、参考と同じ位置へ文字を置いたら顔の目に重なった例が挙がります。守るのは座標ではなく、見せたいものが見えることです。また商品を変えたら、前の商品で使った訴求を流用せず、新しい商品ページで固有の売りを読み直します。
商品ページの一文と、それを見せる自分の素材を一組にする。

次の一回に使う、改善メモを残す。
調査・判断・制作が、一つのメモでつながる状態にします。
01 / 観察 / 参考URLと、実際に見た構造・違和感を書く。 / 02 / 判断 / なぜ変えるか、自分の商品で言えることは何かを書く。 / 03 / 制作 / 自分の素材で変える一点と、作業枠を決める。 / 04 / 見直し / 公開日と確認日を残し、次の投稿へ持ち越す一点を決める。
下のシートには、作業時間だけでなく、参考・判断理由・自分の変更点を記入できます。松岡さんの帰宅後の準備を、自分が再開できる大きさへ置き換えてください。予定枠の最後に、次に開くものまで残すと作業をつなげられます。
シートをまとめて保存し、次の制作時にそのメモから始める。
