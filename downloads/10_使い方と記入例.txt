収益を伸ばす「勝ち筋」の見抜き方

【この教材で作るもの】
変わった数字と、次に確認する箇所を一つ言える。

反応の、どの段階を見ている？
見られた数・クリック・成果発生・確定額は、違う段階の数字です。
1 / 見られる / 表示・視聴の数 / 2 / 押される / リンクのクリック / 3 / 成果が記録される / 発生した件数・金額 / 4 / 承認される / 確定した件数・金額
見られた数が増えたのか、リンクを押す割合が変わったのか、成果が確定したのか。段階を分けると、何が変わったという話なのかを具体的にできます。
「うまくいった」で一括りにせず、どの段階が変わったかを見る。

クリックは増えた。でも、割合は？
前回500回で10クリック、今回1,500回で15クリックとした計算例です。
前回 / 500 / 回見られた / 10クリック / 2.0 / % / 今回 / 1,500 / 回見られた / 15クリック / 1.0 / % / 件数は増加 / 10 → 15クリック / 割合は低下 / 2.0% → 1.0% / 点はクリック率を100分のいくつで表した図です。
前回は500回に対して10クリックなので2.0%。今回は1,500回に対して15クリックなので1.0%。クリック件数は増えていても、見られた数に対する割合は下がっています。
件数が増えたかと、割合が上がったかを分けて見る。

比べる前に、条件をそろえる。
公開後の同じ期間、同じ種類の数、同じ案内先かを先に確認します。
期間 / 公開から同じ日数 / 数の種類 / 表示／視聴などの同じ指標 / 案内先 / 条件やリンクの変更 / 変更点 / どこを変えたかの記録
前回の公開後7日と、今回の公開後1日をそのまま比べない。同じ期間、同じ指標、同じ案内先かを確かめます。条件が違えば、その差を一緒に記録してください。
条件の違いを、コピーの効果と決めつけない。

次の一回で、変えるのは一つ。
今回の案内文が特徴だけなら、次は確認してほしい内容まで示して比較します。
今回の案内 / 折りたたみ式。ケース付きです。 / 次に試す一つ / サイズと購入条件を、商品ページで確認してください。
たとえば案内の一文だけを変えて、ほかの条件をできるだけそろえる。結果を見たあとに、何が影響した可能性があるかを検討しやすくするためです。一回で原因を断定はしません。
変更点を一つにし、同じ期間で次の数を記録する。

確定額と費用も、一緒に残す。
見られた数だけでなく、確定した額と、記入した費用まで同じ記録で見ます。
確定した報酬 / 24,000 / 円 / − / 記入した費用 / 3,000 / 円 / ＝ / 二つの差 / 21,000 / 円
反応が大きくても、確定した報酬や費用の確認は別です。下の比較シートでは、割合の計算と、確定額から記入費用を引いた差を分けて表示します。次に試す変更点は、自分で一つ決めて残します。
下のシートで、前回と今回、次に変える一つを残す。

変える場所を、数字の段階で絞る。
同じ期間と定義をそろえたら、どのつなぎ目を先に確かめるかを選びます。
観察した状態 / 先に確かめる場所 / 表示0件 / 公開状態、計測期間、表示の定義。 / 表示あり・クリック0件 / 案内の見える位置と言葉、リンクが開くか。 / クリックあり・発生0件 / 紹介内容と案内先の一致、成果条件、計測の遅れ。 / 発生あり・承認が少ない / 承認までの時期、取消等の条件、比較期間。
この表は原因の確定ではなく、次に確認する場所を絞るための順番です。少ない件数や異なる期間では割合が大きく動きます。変更は一つにして、何を変えたかと次の確認日を記録します。
前回と今回の条件をそろえ、次に変える一つと見直す日を書く。

【自分の記入欄】
比較する期間と条件：［同じ公開後日数・指標・案内先か］

前回の数字：［表示・クリック・発生・承認・確定額・費用］

今回の数字：［同じ項目を記録］

今回変えたもの：［冒頭・素材・案内等］

次の確認と一つの変更：［原因を断定せず、確かめる仮説を置く］
